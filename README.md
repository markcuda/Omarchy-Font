# Omarchy Font

Open-source release of the `Omarchy Font`, a TrueType conversion of the `Delta Corps Priest 1` FIGlet font.

Download `Omarchy Font.ttf` and install it like any other desktop font. The converted font preserves the original 9-row block-art design using vector rectangles, including full, half, and side block characters. It contains printable ASCII characters U+0020–U+007E.

The original `.flf` and optional converter are included for provenance and reproducibility; users do not need to run the converter.
