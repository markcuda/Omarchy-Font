# Omarchy Font

Vector TrueType conversion of the `Delta Corps Priest 1` FIGlet font.

The TTF preserves the original 9-row block-art design using vector rectangles, including full, half, and side block characters. It contains printable ASCII characters U+0020–U+007E and is suitable for normal font installation and use in applications that support TrueType fonts.

## Build

Run `python3 tools/convert_font.py "source/Delta Corps Priest 1.flf" "Omarchy Font.ttf"`.
