# Omarchy Font

Open-source home for the `Delta Corps Priest 1` FIGlet font.

The repository preserves the original `.flf` file as-is for use with FIGlet-compatible tools.

## Attribution

The original FIGlet font identifies its author as CoSMiC cHiLD and was created with patorjk.com’s FIGFont Editor. The source is included for reference; review the upstream terms before redistributing beyond this repository.

Source: https://github.com/xero/figlet-fonts/blob/main/Delta%20Corps%20Priest%201.flf
